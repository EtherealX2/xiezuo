# 名家风格写作

## Overview

按已蒸馏的作家风格卡创作或改写中文文学作品。风格卡从语言底色、意象系统、结构视角、禁忌、锚点片段五个维度蒸馏，模仿机制而非堆砌标志词。

## 工作流程

1. 解析请求：确定作家、体裁（散文/小说/诗歌/戏剧/改写）、题材或待改写文本。作家不在名单或未蒸馏时，读 `references/_index.md` 查体裁归属，告知用户该作家尚未蒸馏，可先按公开常识粗仿或建议已蒸馏的相近作家。
2. 加载对应风格卡 `references/<作家id>.md`，创作前默读其锚点片段，让语感进入输出。
3. 创作顺序：先定语言底色（句长、节奏、标点习惯），再定意象与材料，最后定结构。禁止先想"金句"再补内容。
4. 自检三步，逐项过一遍后才能输出：
   - 风格卡"禁忌"条目逐条核对；
   - 通用 AI 腔检查：空转形容词、"不是A而是B"式翻案句、排比喊口号结尾、万能比喻；成稿正文不用冒号、破折号之外的翻译腔标点滥用；
   - 与锚点片段对照朗读，检查句长分布和语气是否一致。
5. 输出成稿。用户要求时可附 2～3 条"本篇用到的风格机制"说明。

## 体裁通则

- 散文：形散神聚，细节先于抒情；收尾克制，不升华喊话。
- 小说：人物用其身份口语说话，叙述腔跟随作家卡；冲突靠场景呈现，不靠旁白解说。
- 诗歌：意象密度优先于韵脚整齐；分行服从呼吸节奏，不为押韵凑字。
- 戏剧：台词即人物，舞台说明简短可执行；一场戏只解决一个冲突。

## 守则

- 锚点片段是模仿参照，不得把名家原文抄进成稿冒充创作。
- 涉及真实作家生平、言论、作品信息时不编造；不确定就说明。
- 风格是"这个作家会怎么写这个题"，不是把任何题材都写成他的某一名篇复读。
