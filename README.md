# 写作 xiezuo

中国现当代名家风格蒸馏写作 Skill，适用于 Qoder CLI / Claude Code 等支持 Agent Skills 的客户端。覆盖 32 位作家、散文/小说/诗歌/戏剧四种体裁。

## 这是什么

把名作家的文风"蒸馏"成结构化风格卡，让 AI 按机制模仿，而不是堆砌标志性词汇。每位作家一张卡，包含九个维度：

一句话判断、语言底色、意象与材料、修辞机制、视角与结构、体裁适配、禁忌、锚点片段、检验问题。

使用时先加载风格卡，创作后按"禁忌"与"检验问题"逐项自检再输出，从流程上拦截 AI 腔与失真模仿。

## 安装

```bash
git clone https://github.com/<你的用户名>/xiezuo.git
cp -R xiezuo/xiezuo ~/.qoder/skills/     # Qoder CLI 用户级安装
```

其他支持 Skills 的客户端，将 `xiezuo/` 目录放入对应 skills 目录即可。

## 使用

```
/xiezuo 杨绛 散文 家里的猫
/xiezuo 鲁迅 杂文 论调休
```

也可以自然语言触发："用汪曾祺的笔调写……"（未蒸馏的作家会提示并推荐相近风格）。

## 设计要点

- **禁忌条目与检验问题**：每卡写明该作家"绝不这样写"，输出前逐项核对，比只学"像什么"更能防走样。
- **分期笔法**：巴金（早年呼告/晚年枯瘦）、丁玲（莎菲期/桑干河期）、戴望舒（雨巷期/残掌期）等要求先定时期再动笔。
- **体裁边界**：卡内直接声明该作家不擅长的体裁并建议改用别家，杜绝硬凑。
- **引文诚实**：锚点片段注明出处；凭印象的标"大意"；流传而出处存疑的标"传为某某语"。
